# Six month roadmap

## Month 1

Validate the claim schema with potential users, select lawful sources, publish the repository, and create a 100-claim development set.

## Month 2

Add PDF and HTML normalization, page geometry, tables, source hashes, and complete run manifests.

## Month 3

Add the narrow solid-electrolyte schema, unit normalization, required-condition checks, and initial open-model adapters.

## Month 4

Add source-linked human review, immutable edit history, cautious conflict candidates, and JSON-LD provenance mappings.

## Month 5

Process approximately 100 papers, produce approximately 1,000 records, adjudicate at least 200 held-out records, and compare model profiles.

## Month 6

Complete external pilots and privacy, security, license, and reproducibility checks; publish the v0.1 release and results report.
